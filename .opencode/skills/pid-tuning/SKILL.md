# 泵出口压力虚拟回路调参经验（版本 3）

## SIMULATION 汽水循环 B

若请求声明 `skills_preloaded`，技能正文和本轮授权上下文均已由后端准备，等同已完成加载和读取，无须调用 skill 或 get_tuning_context。直接使用 control_context，将其中的 context_receipt 原样填入 StructuredOutput。流程异常使用 WORKFLOW_ERROR，与没有可信新候选的 NO_CANDIDATE 分开处理。

当请求的 `source_kind` 为 `SIMULATION` 时，给水泵 PID 直接控制给水流量，汽包水位、主蒸汽压力和汽轮机功率是系统级评测信号。四种负荷变化使用同一组参数；候选结果中的 `scenarios` 给出各工况分数和安全越界。优先修复任何工况的安全越界，再考虑综合分与最差工况表现。可以一次改变多个参数并跨较大步长，但不得越过请求中的绝对边界，也不得重复已评测参数。`delta` 始终相对 `current_best.pid`。观察历史结果推断方向，不把现有数值曲线误当作真实设备。没有可信的新候选时返回 ABSTAIN。

加载技能后直接用本次调用凭据读取 get_tuning_context，无需查找其他技能文件或搜索源码。`actual_pid` / `baseline_pid` 是仿真初始参数，`current_best` 是尚未下发的仿真最佳候选，两者不同无需人工复核。综合全部 `history`、`rejections`、四工况指标和剩余预算判断下一组候选，不因一轮改善就视为完成搜索。以下 EXAMPLE 参考区域不适用于 B 回路。

### 仿真搜索与停止

- `search_feedback` 给出程序计算的总分方向、相对基线的改善量、当前阶段及未试验的单参数建议。先通过所有安全边界，再降低综合分 `0.7×四工况平均分+0.3×最差工况分`；流量、水位、泵动作等分量允许相互权衡，不要求每项都下降。只能把总分下降称为综合改善，不因某个分量变差就认定搜索方向不明。
- 对 `steam-cycle-b-v1/v2`，压力与功率子系统在该简化模型中不接收给水流量反馈，因此二者不随泵 PID 改变。它们仍参与评分，压力仍是安全约束，但不能指望增大 kp/ki/kd 降低不变的 pressure/power 分量。不可控压力已越界时，允许说明“该回路状态无法仅靠泵 PID 恢复安全”并停止；不得放宽安全界或修改老化状态。
- `INITIAL_EXPLORATION` 建议先评测至少 3 个候选。只有基线和一次多参数改变不足以判定某一参数的作用；有预算时可以围绕当前最佳只改变 kp、ki 或 kd，作正向/反向有界探测，其他参数保持不变。候选不必预先保证分数下降，未改善或越界由离线模拟器裁决，记录也可用来判断方向。不要仅以样本少、指标方向不一致、无法保证改善为理由过早 ABSTAIN。
- `untried_single_parameter_probes` 是未验证的建议，由你选择、缩小步长或另提有依据的候选。不得声称建议已经评测，也不得重复历史/被拒绝参数。局部方向已被实际试验证伪时缩小步长或换参数，不能仅因仍有预算而无限盲搜。
- 若收到 `early_abstain_review`，前次放弃已被确认，这是同轮最多一次的复核，不是流程错误。依据综合改善量和单参数试验重新判断；仍无合理候选可再次 ABSTAIN 并说明证据。真正的流程错误继续用 WORKFLOW_ERROR。

以下小步规则只适用于 `EXAMPLE` 回路。

本回路目标为 30 demo_unit，观测 JSONL 由持续运行的虚拟采样器写入。它没有真实设备写入通道。Control 读取的 observation_state 与 observation_metrics 来自冻结窗口；current_best 和 history 是此前离线试验的结果。两者可能不一致，因为候选参数从未应用到持续采样系统。

## 过程特性

- `kp` 影响比例响应和暂态振荡；`ki` 影响积分偏置和稳态误差；`kd` 影响振荡衰减。三个参数在示例模型中耦合，不能单凭一个指标大幅跳变。
- 参考区域为 `kp≈1.1, ki≈0.2, kd≈0.05`。离线试验持续 120 秒，包含衰减暂态、与参数相关的振荡、积分偏置及周期负载扰动。低分数不保证所有安全边界合格；必须由编排器验证整条曲线。
- `no_improvement` 工况故意让参数对结果不起作用；如果历史显示不同候选的指标相同，应停止猜测并返回 ABSTAIN，或在证据充分时明确说明无改善预期。
- `coupled_load` 从 `kp=1.0, ki=0.15, kd=0.03` 开始，负载扰动更强；三个参数均偏离参考区域。一次试验的改善不代表已经达标，要利用历史得分比较下一步方向。

## 一次只走一小步

1. 先核对冻结状态、观测质量、当前最佳指标和历史候选。如果状态或指标矛盾，选择 ABSTAIN 并用中文说明。
2. 识别主导问题：持续偏高优先考虑稳态误差，振荡优先考虑标准差和超调，响应慢优先考虑整定时间。只用当前示例允许的状态和指标作判断。
3. 相对 `current_best.pid` 提出一个候选。优先改变最有根据的单个参数；若历史证据支持多个参数的联动，也必须限制每一项的步长。不得重复实际参数或历史候选。
4. 使用请求中提供的绝对界和最大步长；本示例为 kp `0..3 / 0.1`、ki `0..1 / 0.05`、kd `0..0.5 / 0.02`。保持全部原有参数名，`delta = candidate_pid - current_best.pid`，最多六位小数。
5. 用中文说明预期改变的指标、仍需模拟验证的风险。不声称候选已经应用。若无安全且有意义的候选，返回 ABSTAIN，`delta` 和 `candidate_pid` 均为 null。

不可把本示例公式或调参经验用于真实设备；Guard、评测、接受和停止都由编排器裁决。
